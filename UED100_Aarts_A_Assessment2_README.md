# Bank Prototype – UED100 Assessment

## Overview
This project is a front-end banking interface prototype developed using HTML, CSS, and JavaScript.  
It demonstrates responsive design, basic navigation, UI layout, and simple form interaction.

The prototype simulates a digital banking landing page including:
- Navigation menu
- Hero section
- Product cards
- Contact form
- Responsive mobile layout

---

## Technologies Used
- HTML5 – Semantic page structure
- CSS3 – Styling and responsive layout
- JavaScript – Interactive functionality
